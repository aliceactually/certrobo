# EFF long wordlist

`eff_large_wordlist.txt` is the Electronic Frontier Foundation's long
wordlist for randomly generated passphrases, reproduced without modification.
It contains 7,776 lines, each with a five-die code and a word.

- Source: https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt
- Background: https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases
- Copyright: Electronic Frontier Foundation; [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- EFF copyright policy: https://www.eff.org/copyright
- SHA-256: `addd35536511597a02fa0a9ff1e5284677b8883b83e986e43f15a3db996b903e`

This is a source artefact, not yet wired into the application. Any generator
must choose words independently and uniformly using a cryptographically secure
random generator.
